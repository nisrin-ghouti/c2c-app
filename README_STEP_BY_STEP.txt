C2C STEP-BY-STEP UPDATED FILES

This bundle keeps the existing contextual demos that were not part of the requested change.
The main first-run tour is reorganized as:
Intro overlay -> Home -> Events -> My Events -> Points -> Monthly Champions -> Surveys -> Accessibility
-> tap Matches -> Compatibility -> Chat -> tap Profile -> Report
-> tap Scan -> QR camera -> Student number
-> tap Benefits -> Benefits page -> tap Wallet -> Wallet
-> tap Profile.

Main descriptive steps use compact Previous/Next controls and block all other interaction.
Navigation steps are tap-gated so only the highlighted target can be pressed.
Hebrew, English and Arabic strings are included.
The Profile settings replay action now replays only this step-by-step tour, not the removed full-screen onboarding cards.

NOTE: The generated localization Dart files are included so these new strings are immediately available. If you later edit an ARB file, run Flutter gen-l10n again.
